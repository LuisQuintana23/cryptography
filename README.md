# Secure Digital Document Vault

In this project, we'll design and implement a secure system for protecting, sharing,
and verifying digital documents using modern applied cryptographic techniques.

## Project Goal

Build a command-line or simple application that allows users to encrypt files, share them
securely with selected recipients, verify authenticity, and manage their cryptographic keys
responsibly.

## Core Functionalities

- Encrypt files using authenticated encryption (AEAD).
- Generate a unique symmetric key for each file.
- Protect file keys using recipients’ public keys (hybrid encryption).
- Digitally sign documents to guarantee authenticity.
- Verify signatures before decrypting any content.
- Protect private keys using a password-based key derivation function (KDF).
- Allow secure sharing with multiple recipients.
- Provide a basic key backup and recovery mechanism.
